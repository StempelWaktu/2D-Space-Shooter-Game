# 2D Space Shooter

Space Shooter adalah game arcade bergenre shoot 'em up yang dikembangkan menggunakan Unity. Game ini mengangkat nuansa game arcade klasik dengan sentuhan modern, di mana pemain mengendalikan pesawat luar angkasa untuk menghadapi musuh, menghindari serangan, dan memperoleh skor.
Project ini dikembangkan sebagai project UAS Pemrograman Permainan AB di Fakultas Teknologi Informasi, Universitas Budi Luhur.

## Fitur

- Kontrol pesawat
- Menembak musuh
- Random enemy spawn
- Menghindari serangan musuh
- Sistem skor dan nyawa

## Teknologi

- Unity 2022
- C#

## Cara Menjalankan

1. Clone repository.
2. Buka project menggunakan Unity.
3. Gunakan versi Unity yang sesuai.

## Assets

Beberapa asset dalam project menggunakan asset gratis dari pihak ketiga.

- Space Shooter Redux UI — OpenGameArt
- Asset dan audio lainnya digunakan sesuai dengan ketentuan/lisensi dari masing-masing sumber
